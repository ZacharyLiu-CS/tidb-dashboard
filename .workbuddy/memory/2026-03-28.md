# 2026-03-28 工作日志

## TiDB Dashboard NoTiDB 模式实现

在 `feature/easygraph` 分支上实现了 TiDB Dashboard 的 `--no-tidb` 模式，使其能在没有 TiDB 实例的纯 TiKV 集群（tikv-slim 模式）中正常运行。

### 修改概要
- **后端**: 添加 `--no-tidb` CLI 参数和 `NoTiDB` 配置字段
- **认证**: 创建 `noauth` 认证器替代 `sqlauth`（不需要 TiDB SQL 验证）
- **模块**: 新建 `NoTiDBModules` fx 模块集合，排除了 statement、slowquery、queryeditor、diagnose、topsql、deadlock、resourcemanager
- **前端**: 添加 `useIsNoTiDB()` hook，侧边栏根据 no_tidb 状态隐藏 TiDB 依赖功能
- **文档**: plans/ 目录下 5 个步骤文档 + README.md 总结

### 修改的文件
- `pkg/config/config.go` — NoTiDB 字段
- `cmd/tidb-dashboard/main.go` — --no-tidb 参数
- `pkg/apiserver/user/noauth/noauth.go` — 新文件
- `pkg/apiserver/apiserver.go` — NoTiDBModules + 动态路由
- `pkg/apiserver/utils/tidb_conn.go` — 跳过 TiDB 连接
- `pkg/apiserver/info/info.go` — no_tidb 字段
- 前端: 4 个 TypeScript 文件更新

### 测试结果
- 后端编译成功，API 正常工作
- 前端登录正常，侧边栏正确隐藏 TiDB 功能
- 集群信息正确显示 PD + TiKV 实例
